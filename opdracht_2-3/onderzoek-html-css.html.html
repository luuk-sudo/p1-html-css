Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

Webontwikkelaars gebruiken tegenwoordig HTML5, dat officieel wordt onderhouden als de HTML Living Standard door de organisatie WHATWG (Web Hypertext Application Technology Working Group).

De term "Living Standard" (levende standaard) wordt gebruikt omdat HTML niet langer in vaste, genummerde versies (zoals HTML6 of HTML7) wordt uitgebracht. In plaats daarvan is het een continu evoluerend document dat constant wordt bijgewerkt. WHATWG

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

Webontwikkelaars spreken tegenwoordig niet meer over één specifieke CSS-versie (zoals CSS4), omdat CSS sinds 2011 niet meer als één groot blok wordt ontwikkeld, maar is opgedeeld in tientallen onafhankelijke modules.

Toen CSS3 werd uitgebracht, merkte de werkgroep (het W3C) dat de specificatie te groot en complex werd om in zijn geheel te updaten. Als één onderdeel vertraging opliep, bleef de rest ook hangen. MDN Web Docs

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Een website ziet er soms anders uit in verschillende browsers omdat elke browser een eigen rendering engine gebruikt die de broncode (zoals HTML en CSS) op een net iets andere manier vertaalt en interpreteert.

welke drie webbrowsers worden momenteel wereldwijd het meest gebruikt?

De drie wereldwijd meest gebruikte browsers zijn Google Chrome, Apple Safari en Microsoft Edge

Google Chrome: Ongeveer 69% marktaandeel. Dit is met afstand de populairste browser op bijna alle apparaten.

Apple Safari: Ongeveer 16% marktaandeel. Deze browser staat standaard op alle iPhones, iPads en Macs.

Microsoft Edge: Ongeveer 5% marktaandeel. Deze browser staat standaard op Windows-computers en is in populariteit gestegen.
